# sec-toolkit 🔐

Offensive and defensive security scripts for Linux.

## Tools

| Script | What it does |
|---|---|
| `port_scanner.py` | Scans open ports on a target host |

## Usage
```bash
python3 scripts/port_scanner.py 127.0.0.1 1 1024
```
